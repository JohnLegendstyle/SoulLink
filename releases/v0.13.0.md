# Soul Link 0.13.0 · Discord statt Bildübertragung

- Die App startet keinen Bild-Encoder/Upload mehr. Frühere Einstellungen für automatische Bildübertragung werden ignoriert. Keine versteckte Weiterübertragung.
- Website: kompakte Teams nebeneinander, Fangkarte darunter, Pokémon-Paare anschließend. Optionaler Discord-Platzhalter rechts, bei Eddie standardmäßig sichtbar; Breite und Höhe anpassbar.
- Der Platzhalter ist nur freier Platz für ein darübergelegtes separates Discord-Fenster, keine eingebettete Übertragung oder Fernsteuerung.
- Teams etwa alle 25 Sekunden, Fangdaten und Cloud-Spielstände bleiben verbunden. Das Spiel läuft beim Wechsel zu Discord weiter.
- Vollständige Tastenprofile aus 0.12.1 bleiben erhalten. Keine ROM-/Save-/Figurenänderungen.

## Umstellen

**Alte laufende Apps:** im Spielfenster „Übertragung stoppen“ anklicken. Die Website lehnt Bilddaten bereits ab; ältere Apps können bis zum manuellen Stoppen trotzdem Uploads versuchen.

**Beide Spieler:** speichern, Spielfenster schließen, Cloud-Abgleich abwarten, unter Updates direkt auf **0.13.0** wechseln. Website neu laden. Bestehende Runde verwenden; keine Startspielstände importieren.

Downloads: `SoulLink-0.13.0-Windows-x64.zip` und `SoulLink-0.13.0-macOS-arm64.zip`. Alte Installation und Profile bis zur Kontrolle behalten. Tracker, Cloud-Saves und Hosting benötigen weiterhin Datenverkehr; nur die teure integrierte Bildübertragung entfällt.
