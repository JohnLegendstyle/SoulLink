# Robot overworld artwork

Unofficial AI-generated Transformers fan art. Optimus Prime and Bumblebee belong to their respective rights holders. No original Nintendo artwork is included here.

Generated with the built-in Imagegen tool on 2026-09-26 (no CLI/model override). Original tool outputs are the two `*-source.png` files. The tool returned 1254×1254 transparent sheets despite the requested dimensions. `../../tools/compile_skins.py` mechanically divides each image into a 4×4 grid, downsamples to 32×32, unifies the two neutral poses and encodes a shared 15-color-plus-transparency DS palette. It does not read a ROM. The `*-preview.png` files show exactly the compiled colors and pixels, enlarged for inspection. The `*.json` files are the app's runtime assets.

Rows: north, south, west, east. Columns: idle, first stride, idle, second stride. Runtime maps these 16 frames to both walking and running. Supported male overworld sets: hero 69, Rocket hero 95, alternate hero 213. Battle portraits, trainer-card artwork and special-action sheets are not replaced in this version.

Rebuild assets: install Pillow 12.3.0 in a development environment and run `python desktop/tools/compile_skins.py` from the repository root. Pillow is not required by the packaged app.

## Exact Optimus Prime generation prompt

Use case: stylized-concept. Asset type: production Nintendo DS-style overworld pixel-art sprite sheet. Create Optimus Prime (classic red truck-chest with two cyan windshield panels, blue helmet with side antennae, silver mouthplate, blue lower legs, red shoulders) as a small chibi playable robot. EXACT canvas 1024x1024 with a strict invisible 4 column by 4 row grid, 256x256 pixels per cell, 16 equal-size full-body sprites. Each sprite is designed on a 32x32 logical pixel grid and enlarged exactly 8x with crisp square pixel edges; maximum character dimensions 24x28 logical pixels, feet at logical y29, center x16. Transparent background, no ground shadow, no gridlines, no text, no captions, no human trainer. Row 1: back view facing north in all four cells. Row 2: front view facing south in all four cells. Row 3: exact left-facing side view in all four cells. Row 4: exact right-facing side view in all four cells. Each row is a coherent walk animation: column1 neutral standing; column2 left leg forward/right arm forward; column3 identical neutral standing; column4 right leg forward/left arm forward. Same body proportions and colors across every sprite. Chunky clean 16-color palette including transparency; strong readable red and blue identity; no anti-aliasing, no gradients, no lighting effects, no tiny intricate surface noise. This sheet will be cut into 16 equal cells and reduced to 32x32 per frame, so all poses must stay entirely within their own cell with consistent anchor and size.

## Exact Bumblebee generation prompt

Use case: stylized-concept. Asset type: production Nintendo DS-style overworld pixel-art sprite sheet. Create Bumblebee, the recognizable yellow-and-black Transformers robot: bright yellow armored helmet with two short black side fins, cyan eyes, silver face/mouthplate, yellow car-chest with dark windshield panels, black torso joints and black racing-stripe details, yellow chunky boots and shoulders. Cute compact chibi full-body robot, NOT a human costume. EXACT square canvas with strict invisible 4 columns by 4 rows grid, 16 sprites of identical proportions. Transparent background, no shadows, no text or gridlines. Each cell contains a 32x32 logical pixel-art sprite enlarged with crisp square pixel edges, max character footprint 24x28 logical pixels centered x16 with feet at y29. Row1: four back views facing north. Row2: four front views facing south. Row3: four exact left-facing side views. Row4: four exact right-facing side views. Within each row, columns are a walk cycle: neutral standing, left foot/right arm forward, identical neutral standing, right foot/left arm forward. Consistent anchor, size, head design and palette in every cell. Use a very limited 16-color palette including transparency, saturated golden yellow, black charcoal, silver gray and cyan eyes. No gradients, no antialiasing, no intricate noise. Characters isolated entirely inside their own cells with clear padding. This sheet is going into a real low-resolution game, so clean, readable silhouettes and exactly aligned grid cells matter more than fine detail.
